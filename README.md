# 선기왕국 — 휴대폰/브라우저 시험판

이 저장소는 게임 **선기왕국**의 브라우저 판(pygame-ce → WebAssembly, pygbag)입니다.
GitHub Pages 를 켜면 `https://<계정>.github.io/<저장소>/` 에서 바로 실행됩니다.

- 폰은 가로로 돌려서 · 첫 실행은 약 50MB 를 내려받습니다(와이파이 권장)
- 저장은 각자의 브라우저 안에 남습니다
- 글꼴: Noto Sans CJK KR (SIL Open Font License 1.1) — 꾸러미 안 `assets/fonts/OFL.txt`
